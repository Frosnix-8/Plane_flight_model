#Overview
Large aircraft navigation prototype working on making a system where you can fly super fast and walk inside while doing so. it's going well right now, but it's hard. Actually, I completely stopped working on it.

Here is some info you maybe want to have:
move like any game, press F to interact. move regularly in aircraft, use mouse to move. Press Z to toggle flight assist. use a,d e,f and space, shift to adjust lateral plane movement (or forward, backward). for the moment.

for the moment I am alone.

## What exactly is it?
This was my attempt at making a floating origin, varying intertial reference frame model for flight. Essentially, game engines love things that don't move. so if you're in a ship, just make the ship not move and the world move! you can then easily move inside with no issues. but what if you leave it? Change reference! etc etc etc. this was very hard for me because I knew nothing when I began. it was fun but sadly I have more interesting and less brain churning math to do.
