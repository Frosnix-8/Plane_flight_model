Interactive objects. NOTE: NO NEED TO DUPLICATE SCRIPT

guide: 
	-insert in desired location.
	-make local
	-connect signal from script to desired location.
	
Why?
	This code allows you to minimize useless scripts. The script gives you whether the object has been clicked and if it's toggled or not can
	be inferred by the receiver. This also allows you to much more easily adjust all global buttons, since one script handles everything.
	If you can, make any other variants "standard" by using signals to signify output.
